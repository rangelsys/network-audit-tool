# Utilização

## Executando a ferramenta

Abra o PowerShell e execute:

```powershell id="2q4f7o"
.\audit-tool.ps1
```

---

## Funções Disponíveis

### Mostrar IP local

Exibe informações de rede utilizando `ipconfig`.

### Testar conexão

Realiza testes de conectividade utilizando `ping`.

### Ver portas abertas

Lista portas em escuta e conexões de rede.

### Ver conexões ativas

Exibe conexões TCP ativas do sistema.

### Scanner de hosts

Realiza uma varredura simples buscando hosts ativos na rede local.

### Consulta DNS

Realiza consultas DNS utilizando `nslookup`.

### Auditoria completa

Executa múltiplas verificações de rede automaticamente.
